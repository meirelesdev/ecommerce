# Ecommerce

> Plataforma de e-commerce em PHP com painel administrativo, gestao de produtos, categorias e pedidos, com interface responsiva Bootstrap.

## Stack

- PHP

## Prerequisitos

- PHP 7.4+ e Composer

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/ecommerce.git
cd ecommerce

# Instale as dependencias
composer install

# Inicie a aplicacao
php -S localhost:8000
```
